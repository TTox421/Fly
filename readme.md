# Что это?
Флай - система полета, позволяющая летать по карте на клавиши "w", "a", "s", "d", "shift"

# Как установить?
1. Скачайте файлы в архиве.
2. Создайте папку fly и поместите файлы в папку.
3. Если у вас нет проекта, на сайте https://altv.mp/ru/downloads/, скачайте проект.
4. В уже существующий проект, или скачаный с сайта, переместите систему в папку resources.
5. В файле server.toml, добавьте надпись "fly", в поле resources.
